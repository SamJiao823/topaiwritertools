🔧 Clash Verge 客户端配置要点

1️⃣ 端口设置 （关键！踩坑提醒）

端口说明状态
7897Clash Verge 实际代理端口✅ 正确端口
7890常见默认端口❌ Clash Verge 不适用
7891常见默认端口❌ Clash Verge 不适用

⚠️ 不要用 7890 或 7891！ 经过实测，Clash Verge 的实际代理端口是 7897，这是最常踩的坑。

2️⃣ 系统网络设置

✅ 不动系统网络设置 — 只需在 Clash Verge 客户端内完成配置，不需要修改 macOS / Windows 系统级的网络代理设置。

3️⃣ 服务端配置（搬瓦工 + sing-box）

协议: Shadowsocks 加密方式: aes-256-gcm 节点: 搬瓦工 洛杉矶机房

🚀 快速启动步骤

  1. 搬瓦工后台开启 Shadowsocks 服务
  2. 复制节点配置信息（地址、端口、密码、加密方式）
  3. Clash Verge 客户端 → 导入配置
  4. 切换到「搬瓦工-洛杉矶」节点
  5. 确认端口 7897 已开启
  6. 浏览器打开 ip.sb 验证 IP 已变更

📋 验证代理是否生效

# 查看当前公网 IP curl ip.sb # 验证端口连通性 curl -x http://127.0.0.1:7897 https://www.google.com -I

⚠️ 常见问题

问题解决方案
连不上节点检查搬瓦工后台 Shadowsocks 服务是否运行
端口不可用确认 Clash Verge 设置的端口是 7897
网速慢搬瓦工洛杉矶节点一般延迟 150-200ms，可尝试更换机房
UDP 不支持确保服务端 sing-box 配置中启用了 UDP 转发
